# Медиа

## Общая готовность

ЗАПОЛНИТЬ: planned / ready / not_required и короткое объяснение. Значение должно совпадать с meta.json.

## Обложка и иллюстрации

Для каждого элемента повторить блок, удалив ненужные подсказки:

- ID и роль: ЗАПОЛНИТЬ
- Место в тексте: ЗАПОЛНИТЬ
- Относительный файл или публичный источник: ЗАПОЛНИТЬ
- Автор, происхождение, таймкод для видео: ЗАПОЛНИТЬ
- Основание открытого размещения / что нужно выяснить: ЗАПОЛНИТЬ
- Существенная обработка: ЗАПОЛНИТЬ
- Точная подпись для читателя или «не нужна»: ЗАПОЛНИТЬ
- Просмотр окончательного файла и результат проверки: ЗАПОЛНИТЬ

Если изображения не требуются, объяснить почему и убрать пустой блок. Наличие плана не означает готовые медиа.
