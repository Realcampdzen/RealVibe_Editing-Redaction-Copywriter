# Материалы на приём

Здесь находятся рабочие пакеты авторов. На момент создания репозитория очередь пуста; учебный материал лежит отдельно в [examples](../examples/2026-10-19-training-short-post/).

Создайте новую папку из [шаблона](../templates/material/) по [инструкции сдачи](../CONTRIBUTING.md). Выпускающий ищет пакеты по `meta.json` и статусу `ready_for_review`, затем проверяет действительную готовность. Общий редактируемый вручную список не нужен: он быстро расходится с содержимым папок.

Не меняйте чужую папку без задания. Не удаляйте переданный пакет и историю его исправлений ради «чистой очереди».
